# PortNest v0.0.8

本版本改进了服务器重装或 SSH 主机密钥合法变更后的连接恢复流程，同时继续保持严格的主机身份校验。

## SSH 安全与连接恢复

- SSH 主机密钥变化时展示主机地址、旧指纹和新指纹，便于通过可信渠道核验。
- 增加安全确认流程；只有用户明确确认后才更新当前连接的主机密钥记录。
- 取消确认时继续拒绝连接，避免意外信任未知服务器。
- 将用户确认的新指纹直接写入信任记录，重连时仍严格校验，避免盲目信任下一次握手密钥。
- 普通连接和手动重连统一使用相同的安全恢复流程。
- 兼容现有 SSH 后端保存的历史指纹格式。

## 下载与更新

- Windows x64 安装包：`PortNest_0.0.8_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。

> 主机密钥变化也可能表示连接被劫持。请先通过服务器控制台或可信渠道核对新指纹，再在 PortNest 中确认更新。
