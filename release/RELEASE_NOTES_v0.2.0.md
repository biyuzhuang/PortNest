# PortNest v0.2.0 发布说明

## 阶段二：命令模板与命令广播统一撰写窗格

本版本交付路线图阶段二的全部内容，并同步完成 SFTP 阶段一的补强与多项体验优化。

- **统一命令撰写窗格**：命令广播以撰写窗格形式固定在当前会话操作栏下方（终端显示区之后的文档流布局），不再使用浮层遮盖终端内容；展开/收起与区块切换均不影响正在执行的终端会话。
- **命令广播增强**：目标会话改为紧凑下拉多选（默认选中当前会话，支持多选、全选、清空，点击外部自动收起），沿用现有终端写入机制发送文本，并显示已发送/失败/跳过汇总。
- **命令模板**：支持多条独立命名模板，可搜索、新建（草稿不落库）、编辑、删除；模板内容可"复制到命令广播"后由用户发送，不直接执行。
- **设置页命令模板管理**：新增、编辑、删除、重命名，与撰写窗格共用同一数据源（实时同步），无独立弹窗。
- **窄窗口适配**：撰写窗格、目标会话菜单、模板管理卡片与会话操作栏在极窄窗口下的收缩、断行与横向滚动行为修正；终端文字随窗口尺寸自适应缩放（字体、行高、间距按比例调整）。
- **功能取舍**：原任务模板（独立 SSH exec channel、多主机批量执行、结果汇总）撤出交付范围并移除相关后端代码。
- **发布基础设施**：`tauri.conf.json` 版本同步 0.2.0，更新 updater minisign 密钥对；SQLite 新增 `command_snippets` 表与迁移记录。
