# PortNest v0.6.0 发布说明

本版本以界面与交互质量为主：统一设计令牌和四套皮肤 × 明暗主题，重做资产树、资产列表和创建/编辑资产窗口，并集中修复了一轮布局与焦点细节。

## 全新视觉系统

- 颜色、描边、阴影、圆角、间距、字号和动效统一到设计 token；Aurora、Mist、Ember、Midnight 四套皮肤分别适配浅色与深色主题。
- 统一应用外壳、标题栏、左侧导轨、会话标签、状态栏、菜单、弹窗、表单和设置页的表面与焦点样式。
- 提升正文、次要文字、控件边界和状态色的对比度，176 组文字/背景对比度检查全部通过。
- 精简重复的样式层与遗留色值，减少主题和组件改动时的层叠冲突。

## 资产与会话

- 「全部 / 终端 / 数据库」筛选移入左侧导轨，与资产树开关竖向排列，并用分隔线区分导航与筛选。
- 资产颜色标签在资产列表和资产树中显示为名称前的实心圆点；未设置颜色的资产保留占位，名称与图标不会跳动。
- 创建/编辑资产窗口改为紧凑布局：主机、端口、用户名同排；认证方式与密码/私钥同排；颜色标签与色板同排。常规页在 800×600 及更大窗口下一屏可见，窗口过矮时才滚动。
- 资产列表的创建时间与最近连接时间改为单行显示。
- 修复收起资产树时资产面板压到导轨下方、AI 面板遮挡导轨的问题。
- 新建文件夹弹窗和资产搜索框统一为单层边框与焦点环。

## 文件面板与窗口

- 文件管理面板的收起箭头改为右向，展开箭头保持左向；收起状态下面板与导轨不再重叠。
- AI 侧栏、文件面板和服务器概览在窄窗口、收起状态下的布局修复。
- 会话标签、状态点、隧道/编码等操作区统一尺寸与配色。

## 其他

- 顶部全局搜索框恢复常规宽度，窄窗口仍保留占位文案。
- 设置窗口各页面统一到同一套表单、卡片、开关和焦点规范。
- 保留原有连接、文件夹、密钥、设置和终端主题数据；从 v0.5.0 覆盖安装不受影响。

## 下载与更新

- Windows x64 安装包：`PortNest_0.6.0_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。
- 从 v0.5.0 覆盖安装会保留本地连接、文件夹和设置数据。

> 建议安装前退出正在运行的旧版 PortNest。
