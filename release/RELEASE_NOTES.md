# PortNest v0.6.2 发布说明

本版本带来全新品牌图标，并集中优化资产树、文件夹整理、路径导航与设置联动。

## 品牌与应用图标

- 全新无字母 “Port / Prompt” A 标：应用内随主题配色自适应，打包图标采用 Ember 浅色静态版本。
- 主窗口与设置窗口标题栏统一使用新标志，favicon 与各平台应用图标同步更新。

## 资产树与文件夹

- 资产树行收紧为 28px 扁平样式，移除圆角、悬停/选中彩色描边与发光；保留协议彩色图标、颜色圆点、右侧数量、连接列表标题和选中强调条。
- 文件夹支持直接拖拽到其他文件夹、根目录或调整同级顺序；拖动时连同全部子目录与会话按层级整体移动。
- 增加拖拽落点提示：拖入文件夹、插入前/后、移动到根目录均有明确反馈；拖入自身或后代会被阻止。
- 目标文件夹在拖拽悬停时自动展开，移动后自动展开目标及其祖先目录。
- 新建文件夹弹窗只通过右上角关闭按钮退出；新增“创建位置”下拉，可在根目录或任意层级文件夹中创建，并显示完整路径。

## 资产列表与导航

- 面包屑始终显示“资产列表 / … / 当前目录”完整路径，任意祖先目录可点击跳转。
- 窄窗口下路径保持单行并自动定位当前目录；极窄时工具栏自动换行为两行，路径与搜索、操作按钮不再互相挤压。
- 空选中状态不再占用工具栏空间，搜索框宽度随容器自适应。

## 文件管理

- 双击普通文件直接打开现有远程文本编辑器；双击目录仍进入目录。
- 启用“权限”和“用户 / 组”列后，两列表头文字在各自列内居中，表头与数据列保持对齐。
- 储存仓库中的“导入 / 导出”按钮在窄设置窗口中保持单行，不再被压成竖排。

## 设置与窗口

- “SSH/SFTP 路径联动”开关在设置中正式可用，并与文件管理器三点菜单中的同名开关双向同步；跨窗口修改即时生效并持久化。
- 设置 → 基础新增“关闭主窗口时”：每次询问 / 退出应用 / 折叠到托盘。
- 该设置同时作用于标题栏关闭按钮、Alt+F4 与应用菜单“关闭窗口”；关闭询问弹窗中勾选“保存此次选项”会同步更新设置。
- 修复快速搜索输入框被卡片边缘裁切的问题，输入框完整显示并自动聚焦。

## 下载与更新

- Windows x64 安装包：`PortNest_0.6.2_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。
- 覆盖安装保留本地连接、文件夹、密钥和设置数据。

> 建议安装前退出正在运行的旧版 PortNest。
