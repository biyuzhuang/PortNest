# PortNest v0.7.0 发布说明

本版本按 Navicat 的交互习惯重做了整个数据库工作区：对象树、表数据页、表设计器、SQL 查询与结果区全部重写，并新增 SQL / CSV / Excel 的整表导入导出。同时带来新的「霜白」皮肤与全局界面缩放。

## 数据库工作区（重做）

- 对象树改为「连接 → 库 → 表 / 视图分组 → 表 → 列 / 索引 / 外键」的分层结构，展开状态与滚动位置按连接记住。
- 库名右侧可选显示字符集编码；表节点后可显示注释，二者均可在设置里关闭，避免窄面板挤掉名称。
- 单击表默认在右侧展开信息栏（表属性、字段、索引、外键）；也可关闭该行为，只做选中。
- 标签栏统一改为「数据库 / 表 / 查询 / 设计器」四类标签，同一对象重复打开会复用已存在的标签。

## 表数据页

- 工具条重排：复制选中记录、导出选中、导出本页、查看 DDL，以及网格 / 表单双视图切换。
- 数据网格支持列宽拖拽、单元格编辑、行选中与键盘导航；无主键的表自动禁用编辑并给出原因提示。
- 新增表单视图，按行展示字段名、类型与值，适合宽表逐条核对。
- 筛选与排序面板支持多条件组合，条件以标签形式回显，可单独移除。
- 状态栏显示当前页、总行数（可选统计）与执行耗时；每页行数、文本对齐、复合表头、固定主键列、滚动方式与滚轮速度均可在设置中调整。

## 表设计器

- 字段、索引、外键三页签可视化编辑，支持主键、自增、非空、默认值、注释与排序规则。
- MySQL 与 PostgreSQL 双引擎分别生成对应 DDL：预览页可查看完整建表 / 改表语句，确认后再执行。
- 外键编辑支持选择参考表与参考列，删除字段或索引时给出依赖提醒。
- 结构页与设计器共用同一份字段定义，改完立即反映到数据页与提示信息。

## SQL 查询

- 编辑器支持跨库字段提示（可在设置关闭）、关键字高亮与多语句执行。
- 结果区按结果集分标签展示，附消息、执行计划与错误详情；批量执行失败时按设置决定是否中断后续语句。
- 危险语句（DELETE / DROP / TRUNCATE 等）执行前二次确认，可关闭。
- 未保存的查询在关闭标签时提示，避免误丢内容。

## 导入与导出

- 表节点右键新增「导入 ▸ / 导出 ▸」二级菜单：SQL、CSV、Excel 三种格式。
- CSV / Excel 导出按 1000 行分页拉取整表（上限 10 万行）后在前端生成文件；SQL 导出由服务端生成结构与数据。
- Excel 导入读取第一张工作表并转为 CSV，复用 CSV 导入事务：表头需与列名一致，任一行失败整表回滚。
- 内置零依赖的 xlsx 读写，导出的文件可被 Excel、WPS、openpyxl 正常打开，数字与中文均保持原样。

## 右键菜单

- 菜单按光标位置出现，超出视口时自动向左 / 向上回弹，二级菜单在右侧空间不足时改为向左展开。
- 左键点击菜单外任意区域或按 Esc 均可关闭；右键切换目标时直接在当前光标处重开。

## 设置

- 数据库设置按「通用 / 对象树与列表 / 数据表 / SQL 查询」四组分区，组间以分隔线区分。
- 新增「数据库后显示编码」（默认关）与「单击表展开信息栏」（默认开）。

## 界面

- 新增「霜白」皮肤：纯白表面配石墨灰强调，浅色下最中性的一套配色。
- 新增全局缩放 50%–200%，文字、图标、终端与数据库同步缩放，支持 Ctrl + 滚轮逐档调整。
- 数据库模块统一使用彩色对象图标（MySQL、PostgreSQL、表、视图、文件夹等），明暗主题下保持品牌色。

## 下载与更新

- Windows x64 安装包：`PortNest_0.7.0_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。
