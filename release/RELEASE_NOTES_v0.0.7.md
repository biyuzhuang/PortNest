# PortNest v0.0.7

本版本集中优化了 PortNest 的界面一致性、终端外观和日常操作体验，同时保持现有 SSH、SFTP、本地终端和 MySQL 核心业务流程不变。

## 界面与交互

- 建立统一的明亮、暗黑及跟随系统主题视觉规范。
- 统一按钮、输入框、菜单、弹窗、字体、间距、圆角和交互反馈。
- SSH、本地终端和 MySQL 使用不同的协议图标，会话状态改为独立指示灯。
- 优化资产树与会话工作区之间的间距、边界和层级，使整体布局更加协调。
- 全面阻止 WebView 原生右键菜单，由 PortNest 自定义菜单统一接管。
- 优化窗口最小化、最大化/还原和关闭按钮，并增加退出二次确认。

## 设置与终端外观

- 设置界面改为单实例、非模态的独立系统窗口，主窗口可继续操作。
- 设置窗口支持拖动，主题和终端外观变更会即时同步到主窗口。
- 终端配色支持跟随应用明暗主题，并可分别保存浅色和深色方案。
- 新增 One Dark、Nord、Tokyo Night、Catppuccin Mocha、Gruvbox、GitHub、Quiet Light 等多套终端配色。
- 支持主题背景、自定义纯色、午夜渐变、极光渐变和本地背景图片。
- 背景图片支持覆盖、包含、拉伸、透明度、遮罩和模糊调节，并存储在本地 IndexedDB。
- 调整终端内容留白和背景层实现，改善终端与窗口的视觉衔接。

## SSH 与会话体验

- 移除 PortNest 主动写入的 `Connected to` 和 `Host` 欢迎信息，保留服务器真实输出。
- 执行 `exit` 后将远端 Shell 关闭识别为正常会话结束，不再显示连接失败或触发自动重连。
- 修复浅色终端外围黑框、暗黑模式标签栏亮色冲突等显示问题。
- 改进应用退出顺序：先关闭设置等辅助窗口，再关闭主窗口。

## MySQL 工作区

- 统一数据库、数据表、视图、查询、刷新、执行、导入和导出图标。
- 优化对象树、SQL 编辑器、结果表格、设计器、分页、弹窗和右键菜单样式。
- 提升暗黑主题下数据库表图标、对象名称和辅助文字的可读性。
- SQL 和技术字段使用统一等宽字体，其他区域使用全局界面字体。

## 下载与更新

- Windows x64 安装包：`PortNest_0.0.7_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。

> 建议安装前退出正在运行的旧版 PortNest。覆盖安装会保留本地连接和设置数据。
