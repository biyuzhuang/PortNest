# PortNest v0.4.0 发布说明

## 阶段三：SSH 主机状态仪表盘

本版本交付路线图阶段三的全部内容：面向 Linux 主机、无代理安装、全部通过只读命令采集的服务器状态仪表盘。

### 新增

- **收起形态·精简导轨**：终端区右缘固定 56px 导轨，展示 CPU 使用率（1 位小数）、上行/下行速率、CPU/内存/磁盘三个使用率刻度条（内嵌百分比，按阈值变色）；点击展开详细面板。
- **展开形态·详细面板**：
  - 基础信息：主机名、系统、内核/架构、运行时长、登录用户、负载；
  - 指标瓦片：平均/用户态/内核态 CPU、I/O 等待、总 CPU；
  - 物理内存与 Swap 使用率进度条；
  - 网络累计上下行与速率（只统计真实物理网卡，自动排除 docker/veth/bridge 等虚拟接口的重复计数），CPU/内存历史短趋势；
  - 分核 CPU 使用率；
  - GPU（存在 nvidia-smi 时自动展示，缺失则整区跳过）；
  - 进程 Top 12（按 CPU 排序，`sshd: user [priv]` 与其会话进程自动合并为 `sshd: user@pts/N` 单行）；
  - 磁盘挂载列表与容量占比。
- **一键复制诊断摘要**：生成含全部指标与降级说明的文本并写入剪贴板。
- **设置页**：SSH 分区新增「服务器概览」卡片——总开关（默认开启）与刷新频率（默认 10 秒）；设置运行在独立窗口，改动经 storage 事件跨窗口即时同步，无需重启。总开关关闭时面板整体隐藏并停用全部采集；立即刷新按钮独立于自动周期。

### 采集设计

- 七个探测组并发执行，每组独立超时；单组失败只降级该组并保留上次结果标记陈旧，能力缺失的指标自动跳过。
- 采集通过会话池与终端共享同一条 SSH transport，使用独立 Exec Channel，不写入用户 PTY，不影响终端会话。
- 仅在终端 SSH 会话健康时采集；会话异常时自动取消采集并释放会话租约。
- 采集命令全程只读，命令字符串不含 "ssh" 字样，远端 `ps -ef | grep ssh` 撞不到采集器自身。

### 其他改进与修复

- 终端字号不再随窗口尺寸缩放：最大化/还原窗口只改变行列数，字体大小保持设置值。
- 服务器概览开合后对活动终端强制重新适配，修复偶发的终端显示异常。
- 命令广播撰写窗格高度可拖拽调整，布局与交互优化。
- 修复进程列表解析在多空格对齐输出下的列错位问题（名称/内存/百分比值）。
