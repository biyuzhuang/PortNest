# PortNest v0.5.0 发布说明

本版本新增 BYOK AI 助手、PostgreSQL / 瀚高数据库工作区，并完成数据库管理、界面视觉和会话体验的一轮集中升级。

## AI 助手

- 支持使用自己的 API Key（BYOK）接入大模型，API Key 使用本地加密存储。
- 内置 OpenAI、Claude、DeepSeek、Kimi、GLM、OpenRouter、MiniMax、小米 MiMo、阿里百炼、火山方舟、腾讯云混元、Ollama 和自定义供应商模板。
- 支持 OpenAI Chat Completions、Anthropic Messages 和 Ollama 兼容协议。
- 提供通用 Agent、终端增强 Agent 和 SQL Agent 三种工作模式。
- 终端增强模式会自动附带当前会话最近终端输出；SQL Agent 会自动附带当前数据库、编辑器 SQL、表结构和结果预览上下文。
- 支持模型列表自动获取、连接测试、上下文窗口、最大输出 Token、温度配置和多轮历史自动裁剪。
- AI 回复支持流式输出和 Markdown 代码块展示。
- AI 提出的终端命令和 SQL 工具调用必须由用户确认后执行，并按风险等级提示；高风险操作需要二次确认。
- 工具执行结果会自动回传给模型继续分析，所有已接受的命令和 SQL 均写入本地审计记录。

## PostgreSQL / 瀚高数据库

- 新增 PostgreSQL 数据库工作区，并通过 PostgreSQL 兼容协议适配瀚高数据库（HighGo）。
- 支持数据库、数据表、视图和字段结构浏览。
- 支持 SQL 编辑、执行与查询结果表格。
- 支持建表、结构预览、修改、重命名、复制、清空和删除。
- 支持表数据分页浏览，以及记录新增、修改和删除。
- 支持查看建表语句、索引和字段信息，导入 CSV / SQL 和导出数据库 SQL。
- 数据库前端 API 与工作区按协议分派，为后续扩展更多数据库类型复用现有 UI。

## 数据库与界面改进

- 优化 MySQL 工作区的连接、查询、对象树、结果表格、表设计器和数据导入导出流程。
- 统一数据库树、工具栏、编辑器、结果表和右键菜单的明暗主题样式。
- 更新全局视觉风格、设置窗口、表单、菜单、弹窗和键盘焦点样式。
- 优化侧边栏、资产列表、终端标签和窄窗口布局。
- 改进终端搜索、文本右键菜单、命令广播和会话上下文交互。
- 修复若干数据库查询、连接状态和页面刷新问题。

## 下载与更新

- Windows x64 安装包：`PortNest_0.5.0_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。
- 从 v0.4.0 覆盖安装会保留本地连接、文件夹和设置数据。

> 建议安装前退出正在运行的旧版 PortNest。
