# PortNest v0.0.9

本版本重点完善 SSH 隧道与代理能力，并统一优化应用界面和设置体验。

## SSH 隧道与代理

- SSH 终端、SFTP 与隧道共享连接会话，关闭终端时不会误停仍在使用的隧道。
- 完善本地转发、远程转发和动态 SOCKS5，增加真实链路测试、运行状态、活动连接和错误诊断。
- 完善 SOCKS5 与 HTTP CONNECT 代理的认证、握手、超时和错误处理。
- 新增单级 SSH 跳板机支持，可引用已有 SSH 资产并验证跳板到目标主机的完整链路。
- 代理密码改为加密存储，并兼容迁移旧配置中的明文密码。
- 修复隧道配置输入时焦点丢失的问题。

## 界面与设置

- 统一主窗口、弹窗、抽屉、设置和数据库工作区的字体及控件风格。
- 优化资产列表工具栏、开关、连接弹窗关闭按钮和颜色标签选择器。
- 合并应用与终端外观设置，新增主题、终端配色、字体和背景的实时预览。
- 新增独立版本页面，并重新整理 SSH、终端和 SFTP 设置项。

## 下载与更新

- Windows x64 安装包：`PortNest_0.0.9_x64-setup.exe`
- 安装包附带 Tauri Updater 签名，可供应用内更新验证。
