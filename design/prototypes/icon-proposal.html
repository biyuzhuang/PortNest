PortNest · 彩色图标替换方案（待确认）

现状：全站图标是 24×24 的单色线条（stroke: currentColor），跟着文字颜色走，所以在浅色皮肤下基本是灰的。
替换原则：“类型/对象”类图标上色（一眼分辨 MySQL / PostgreSQL / 终端 / 表 / 视图 / 查询），纯操作类图标保持单色（关闭、加号、搜索、刷新、排序、复制、删除等），否则工具栏会变得花而且吵。

尺寸沿用 24 网格，可直接 13 / 14 / 16 / 18 / 20 px 复用 浅色 / 深色皮肤都不换色（品牌色恒定） 禁用态只用 55% 透明度，不再变灰
