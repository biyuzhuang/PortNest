结构对齐 Navicat

  • 第一行：保存 · 添加/插入/删除字段 · 主键 · 上移/下移，右侧放"变更数 + 应用"
  • 第二行：字段 / 索引 / 外键 / 触发器 / 选项 / 注释 / SQL 预览 七个选项卡
  • 第三行：字段网格，列序与 Navicat 一致：名、类型、长度、小数点、不是 null、虚拟、键、注释
  • 底部：当前字段的默认值等高频属性；其余低频项放「选项」「注释」页

与旧稿的差异

  • 取消"字段清单 + 右侧属性栏 + 右侧变更预览"三栏，全部收进网格
  • SQL 预览不再是常驻窄栏，改为独立选项卡（点开占满网格区，只读）
  • 新增行以琥珀底标出，未保存前右侧对象树显示"改"角标
  • 应用变更仍在工具条右侧，需先在 SQL 预览页确认语句

14状态与交互规范

同一套控件在五种状态下的表现必须一致，否则用户会以为"这里坏了"。下面这张表可直接作为组件实现的验收清单。

状态视觉行为
加载中表格保留表头与骨架行；按钮内图标替换为 12px 转圈，文字不变不遮挡已有数据；超过 400ms 才显示，避免闪烁
空（无数据）表头保留，内容区居中 1 行说明 + 1 个主按钮区分"没有表""筛选无结果""没有权限"三种文案
空（无页签）图标 + 标题 + 说明 + 三个入口 + 快捷键入口与工具栏同名同序，避免两套叫法
错误页签内联错误条（浅红底、左图标、右关闭），不弹窗错误归属到具体页签；连接断开才升级为全局提示
禁用整体 45% 透明度，保留形状与位置不做灰度处理，避免与"加载中"混淆；悬停显示原因
只读状态栏出现锁图标；编辑类按钮禁用；单元格不出现编辑光标切只读需二次确认，切换后立即影响所有页签
有未提交修改页签标题后加圆点；底部编辑条常驻；应用按钮为主色关闭页签 / 切库时拦截确认，Esc 只撤销当前单元格
选中浅灰底 + 左侧 2px 强调条；文字颜色不变多选时强调条只在首行，其余行仅底色
焦点2px 强调色描边，偏移 1px仅键盘可见（:focus-visible），鼠标点击不显示

需要你确认的三件事

01
默认视图

对象列表默认停在「列表」还是「表格」？设计稿按列表做默认——信息密度低、注释可读，切表格只是点一下。

02
信息栏是否默认展开

信息栏占 352px，展开后对象列表的注释列会明显变短。设计稿按"单击某张表才展开"处理，避免一进来就挤。

03
设计器的预览位置

现实现是右侧窄栏（约 300px），SQL 会被截断；设计稿改为底部通栏。若要保持现状，只需把宽度调到 380 以上。
