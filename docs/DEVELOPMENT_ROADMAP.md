# PortNest 功能开发路线图

本文档记录 0.0.9 之后六个核心能力的开发顺序、范围和验收标准。实施顺序固定，后续阶段可以复用前一阶段形成的任务、事件、存储与审计基础设施。

## 总体路线

| 阶段 | 目标版本 | 主题 | 预计周期（单人） |
| --- | --- | --- | --- |
| 1 | 0.1.0 | SFTP 专业化 | 3–4 周 |
| 2 | 0.2.0 | 命令片段和任务模板 | 2–3 周 |
| 3 | 0.3.0 | tmux 会话保持与自动恢复 | 1–2 周 |
| 4 | 0.4.0 | SSH 主机状态仪表盘 | 3–4 周 |
| 5 | 0.5.0 | 端到端加密同步 | 4–6 周 |
| 6 | 0.6.0 | 会话日志和回放 | 3–4 周 |

## 公共基础设施

- 引入可追踪的数据库结构迁移，禁止依赖隐式表结构变化。
- 建立统一后台任务模型：状态、进度、取消、重试、错误码、事件通知和恢复策略。
- 导入导出格式带版本号；新字段保持向后兼容。
- 所有长任务必须可取消，应用异常退出后必须能识别并恢复或明确标记为中断。

## 阶段一：SFTP 专业化（0.1.0）

### 当前实施状态（2026-09-17）：已完成

阶段一范围已经全部实现：数据库迁移、持久传输记录、异常退出后的中断标记、文件及递归目录上传/下载、可配置并发队列、多文件批量上传、单任务限速、断点续传、四种同名冲突策略、临时文件安全提交、可选 SHA-256 校验、传输中心、失败/中断续传、历史清理，Unix 权限/UID/GID 修改，以及带并发修改保护的远程 UTF-8 文本编辑器。

阶段一已进入 0.1.0 发布验收；后续新增需求不再作为阶段一遗留项，按独立版本规划。

### 范围

- 持久传输记录：上传、下载、状态、字节进度、失败原因、创建/完成时间。
- 断点续传：下载使用本地 `.portnest.part`，上传使用远端 `.portnest.part`；取消和网络中断保留断点。
- 冲突策略：询问/覆盖、跳过、自动重命名、续传。
- 可靠完成：先写临时文件，成功后原子替换目标；可选 SHA-256 完整性校验。
- 传输中心：查看运行、完成、中断和失败任务；支持取消、重试、清理历史。
- 目录与批量传输：递归上传/下载目录，多选文件按队列上传；符号链接目录默认跳过以避免循环。
- 队列控制：并发数可在 1–8 间配置，支持按单任务设置 KB/s 限速。
- 文件属性：查看并修改 Unix 权限；保留用户/组、链接和时间信息展示。
- 远程文本编辑：最大 2 MiB、仅 UTF-8 文本、安全临时文件写回；保存前使用 SHA-256 检测外部修改。
- 专业浏览：过滤、隐藏文件、列设置、路径历史、终端路径联动继续可用。

### 验收标准

- 传输中断后重新执行相同任务能从临时文件偏移继续，不重复传输已完成数据。
- 覆盖操作不向用户暴露半成品；失败或取消后原目标保持不变。
- 应用重启后能看到未完成任务为“已中断”，重新连接后可重试。
- 同名文件四种冲突策略行为一致，自动重命名不会覆盖已有文件。
- 可修改文件或目录的权限，并在刷新后看到正确的符号权限。
- 单元测试覆盖断点计算、冲突命名、状态迁移与持久化；SSH 集成测试覆盖上传、下载、取消、续传和校验。

## 阶段二：命令片段和任务模板（0.2.0）

- 区分“片段”（插入终端）与“任务”（独立 exec channel 执行）。
- 支持文件夹、标签、搜索、收藏、变量定义、默认值、枚举和敏感变量。
- 任务支持单机/多机、串行/有限并发、超时、取消、stdout/stderr、退出码和结果汇总。
- 危险命令分级确认；敏感变量不进入普通日志或导出。
- 验收：参数渲染可预测，多主机执行可取消，失败主机可单独重试。

## 阶段三：tmux 会话保持与自动恢复（0.3.0）

- 连接后检测 `tmux`，使用稳定格式列出远端会话。
- 支持创建、附加、分离、重命名和关闭；会话名严格转义与校验。
- SSH 重连后按用户策略自动恢复上次 tmux 会话；不存在时可创建。
- 验收：网络中断、应用重启、服务端会话消失三种情况均有明确恢复结果。

## 阶段四：SSH 主机状态仪表盘（0.4.0）

- 第一版面向 Linux，无代理安装，通过只读命令采集 CPU、内存、磁盘、负载、网络、进程和基础系统信息。
- 采集器具有超时、取消、缓存、部分失败降级和能力探测。
- 仪表盘支持刷新频率控制、阈值状态、历史短趋势和复制诊断摘要。
- 验收：低权限账户和缺少命令时仍能展示可用指标，不阻塞终端会话。

## 阶段五：端到端加密同步（0.5.0）

- 默认同步连接、文件夹、片段、任务和非敏感设置；凭据由用户显式选择；日志默认排除。
- 主密码使用 Argon2id 派生密钥，内容使用 AEAD 分项加密；服务端只保存密文。
- 先实现本地加密备份，再实现 WebDAV，最后提供 Git 存储适配器。
- 使用修订号、设备 ID、墓碑与冲突副本处理多端并发，不静默覆盖。
- 验收：错误密码无法解密，服务端泄露不暴露明文，多端冲突可恢复。

## 阶段六：会话日志和回放（0.6.0）

- SQLite 保存会话元数据；终端原始输出以带时间戳的压缩流文件保存。
- 默认不记录键盘输入；可配置隐私模式、脱敏规则、保留周期和单会话上限。
- 基于 xterm 进行暂停、倍速、跳转和搜索回放；文本索引使用 FTS5。
- 导出明确区分纯文本、原始流和脱敏副本。
- 验收：大日志不一次性载入内存，回放时序正确，清理策略不会删除进行中的日志。
